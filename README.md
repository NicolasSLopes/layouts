# Layouts

## Sobre o Projeto

Este projeto consiste em uma coleção de diversos exercícios práticos focados no desenvolvimento de layouts web, com o objetivo de treinar técnicas de front-end e aprimorar habilidades de estruturação e posicionamento de elementos utilizando HTML e CSS.

A proposta foi explorar e dominar diferentes formas de criar estruturas de páginas, desde modelos mais tradicionais até os mais modernos, organizando o conteúdo de maneira fluida e compreensível através do código.

---

## Funcionalidades

* Criação de múltiplos exercícios focados em layouts variados.
* Estruturação de páginas web utilizando tags semânticas do HTML.
* Estilização e posicionamento de elementos com CSS avançado.
* Prática com diferentes técnicas de alinhamento e distribuição de espaço.
* Organização limpa e modular dos arquivos de estilo para cada exercício.

---

## Tecnologias Utilizadas

* **HTML5**
* **CSS3**

---

## Objetivo

O principal objetivo deste projeto é servir como um laboratório de testes para praticar a recriação e a lógica por trás de diferentes estruturas de layouts existentes na web, aplicando conceitos fundamentais e avançados de HTML e CSS.

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos como:

* Estruturação e semântica de páginas HTML.
* Uso de técnicas de layout em CSS (como posicionamento, floats ou seletores específicos).
* Organização estruturada de arquivos e diretórios do projeto.
* Criação de layouts personalizados e adaptáveis.
* Resolução de problemas comuns de alinhamento e espaçamento em front-end.

## Como Executar

1. Clone este repositório:
```bash
git clone [https://github.com/seu-usuario/Layouts.git](https://github.com/seu-usuario/Layouts.git)
```

2. Acesse a pasta do projeto:
```bash
cd Layouts
```

3. Abra qualquer um dos arquivos HTML dos exercícios em seu navegador de preferência para ver o resultado.
